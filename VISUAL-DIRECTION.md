# Ashen Reach — visual production standard

The owner-approved cinematic renders define the target, not proof of current rendering. Preserve the existing playable engine. Never substitute a static image for navigable geometry or fabricated telemetry for simulation.

## Nacre exterior
Hero silhouette: monumental ivory pylons and arch, basalt cliff terraces, wet ocean, amber runway lamps, orange cranes, freighters and blue exhaust. Build the landing corridor in the planetary tangent frame, a named physical pad, a visible approach beacon and persistent hull occupancy. A dock request must validate distance, speed, altitude and clearance. Fly to the pad and return to the same hull without a hidden relocation.

## Flight and cockpit
Reference: cockpit descent over Kestral Cliffs. Charcoal canopy ribs, layered instrument panels, restrained cyan/amber lines, live velocity, clearance, radial speed, target and hull. The first pass adds these instruments to continuous flight. Next: actual 3D cockpit mesh with PBR materials, canopy reflections, physical display textures, camera-relative geometry, atmospheric lighting, terrain shadows and clouds. Heading currently represents an absolute world-frame vector angle, not geographic compass north. Replace with local tangent heading before navigation certification.

## Freeport
Reference: Nacre departure market. Walkable hangar with parked vessel, refit desk, cargo bays, departures board, civilians and active freight. Signage follows actual locations, departures follow real manifests, repairs and trades mutate shared ledger. No decorative buttons or fake population.

## Graphics gates
Capture real renders at named coordinates in chase, cockpit and on-foot views. Compare composition, geometry, lighting, materials, visual density and readability against reference art; measure desktop/mobile frame pacing and memory. Preserve software fallback. Test both camera modes, touch and keyboard input, destination behind camera, pause and resize. No claim of cinematic parity until measured visual review. Use the [original reference archive and checksum manifest](game-design/references/README.md) for the comparison. The main README gallery uses existing game assets, not those targets.
